# المنيو الإلكتروني — متعدد الفروع

منيو رقمي بلوحة تحكم: أقسام ومنتجات بالصور والأسعار، عدة فروع (لكل فرع منتجاته ورقم واتساب)، وإرسال الطلب إلى واتساب.

## التشغيل محلياً
```
npm install
ADMIN_PASSWORD=كلمة_سر npm start
```
افتح http://localhost:3000

## النشر
1. أنشئ مستودعاً على GitHub وارفع كل ملفات هذا المجلد.
2. في Render: **New → Blueprint** واختر المستودع (يقرأ render.yaml).
3. اكتب `ADMIN_PASSWORD` عند الطلب.
4. بعد النشر افتح `رابطك/#admin` وأدخل كلمة المرور، ثم ⚙️ لوحة التحكم.

## ملاحظات
- البيانات تُحفظ في `DATA_DIR/menu.json` والفيديو في `DATA_DIR/uploads`. على Render يجب أن يكون هناك **قرص دائم (Disk)** وإلا تضيع التعديلات عند إعادة التشغيل. الخطة المجانية لا تدعم القرص.
- رابط فرع مباشر للباركود: `رابطك/#معرّف_الفرع` (يظهر في لوحة التحكم).
- لا تنسَ تغيير كلمة المرور الافتراضية.
