# المنيو الإلكتروني — متعدد الفروع

منيو رقمي بلوحة تحكم: أقسام ومنتجات بالصور والأسعار، عدة فروع (لكل فرع منتجاته ورقم واتساب)، وإرسال الطلب إلى واتساب.

## التشغيل محلياً
```
npm install
ADMIN_PASSWORD=كلمة_سر npm start
```
افتح http://localhost:3000

## النشر
1. أنشئ مستودعاً على GitHub وارفع كل ملفات هذا المجلد.
2. في Render: **New → Blueprint** واختر المستودع (يقرأ render.yaml).
3. اكتب `ADMIN_PASSWORD` عند الطلب.
4. بعد النشر افتح رابط الإدارة السري `رابطك/<ADMIN_PATH>` (يُضبط بالمتغير ADMIN_PATH) وأدخل كلمة المرور، ثم ⚙️ لوحة التحكم. لا يظهر أي زر أو رابط للإدارة في المنيو العام.

## ملاحظات
- البيانات تُحفظ في `DATA_DIR/menu.json` والفيديو في `DATA_DIR/uploads`. على Render يجب أن يكون هناك **قرص دائم (Disk)** وإلا تضيع التعديلات عند إعادة التشغيل. الخطة المجانية لا تدعم القرص.
- رابط فرع مباشر للباركود: `رابطك/#معرّف_الفرع` (يظهر في لوحة التحكم).
- لا تنسَ تغيير كلمة المرور الافتراضية.

## نشر مجاني مع حفظ دائم (Supabase)
1. أنشئ مشروعاً مجانياً في supabase.com، ثم من **SQL Editor** شغّل محتوى `supabase.sql` مرة واحدة.
2. من **Project Settings → API** انسخ `Project URL` ومفتاح `service_role`.
3. في Render أضف المتغيرين `SUPABASE_URL` و`SUPABASE_KEY` (إلى جانب `ADMIN_PASSWORD`).
بدون هذين المتغيرين يعمل الموقع بالتخزين المحلي (مؤقت على الخطة المجانية).

## نشر مجاني مع Render Postgres
`render.yaml` ينشئ قاعدة Postgres مجانية ويربطها بالخدمة عبر `DATABASE_URL`. البيانات والفيديوهات تُحفظ فيها.
تنبيه: قاعدة Render المجانية تنتهي بعد 30 يوماً من إنشائها (14 يوم مهلة ثم تُحذف). نزّل نسخة من المنيو قبل ذلك أو رقّها لخطة مدفوعة.
