# المنيو الإلكتروني — متعدد الفروع

منيو رقمي بلوحة تحكم: أقسام ومنتجات بالصور والأسعار، عدة فروع، طاولات برمز QR، طلبات تُسجَّل وتُرسل عبر واتساب.

## التشغيل محلياً
```
npm install
ADMIN_PASSWORD=كلمة_سر npm start
```
افتح http://localhost:3000 — بدون `DATABASE_URL` تُحفظ البيانات في مجلد `data/`.

## النشر على Render
1. **New → Blueprint** واختر المستودع (يقرأ `render.yaml` وينشئ الموقع وقاعدة Postgres).
2. اكتب `ADMIN_PASSWORD`.
3. (نشر يدوي) أنشئ Postgres ثم Web Service، وأضف المتغيرين `DATABASE_URL` (الرابط الداخلي) و`ADMIN_PASSWORD`.

## لوحة التحكم
الرابط الوحيد: `رابطك/admin.html`. الدخول: البريد الفارغ (أو `ADMIN_EMAIL`) + `ADMIN_PASSWORD` للمالك، أو بريد المستخدم ورمزه.
الصفحات: الرئيسية، المطعم، الفئات، المنتجات، الطلبات، الطاولات ورمز QR، الفروع، العروض، السمات، التقييمات، المستخدمون، النسخ الاحتياطي، الحساب.

## الحفظ والمزامنة
- كل شيء يُحفظ تلقائياً في قاعدة Postgres على السيرفر ويراه الجميع مباشرة: المنيو والأسعار والأقسام والصور والفيديو والسمات والشعار ومعلومات المطعم والطاولات والمستخدمون والطلبات.
- الصور والفيديو تُخزَّن في القاعدة وتُقدَّم من `/uploads/`.
- أي تعديل من مستخدم يظهر عند الآخرين (لوحة التحكم والمنيو) خلال ثوانٍ دون تحديث.
- تعارض التعديل المتزامن يُكتشف بنسخة (`_v`) وتُحدَّث الصفحة تلقائياً.

## الطاولات
كل طاولة لها رابط QR موقَّع (`/t/<فرع>/<طاولة>/<توقيع>`): رقم الطاولة ثابت في الطلب ولا يمكن تغييره من الرابط. السر يُحفظ مع البيانات (أو `TABLE_SECRET`) ويدخل في النسخة الاحتياطية، فلا تبطل الباركودات المطبوعة.

## الطلبات والأكثر طلباً
كل طلب يُسجَّل على السيرفر (مع الطاولة الموثَّقة) ثم يُفتح واتساب. قسم «🔥 الأكثر طلباً» يُحسب تلقائياً من الطلبات (يُخفى من صفحة «المطعم»).

## النسخ الاحتياطي
لوحة التحكم ← النسخ الاحتياطي (للمالك): تنزيل نسخة كاملة (ملف JSON فيه كل شيء حتى الصور والمستخدمين)، استيرادها ونشرها، ونسخ تلقائية على السيرفر (آخر 40) يمكن استعادتها.
قاعدة Render المجانية تنتهي بعد 30 يوماً — احتفظ بنسخة وأعد استيرادها في قاعدة جديدة.

## المستخدمون والصلاحيات
المالك يضيف مستخدمين بالبريد والرمز ويحدد صلاحياتهم (معلومات، إضافة، تعديل، حذف، عروض، طاولات، فروع). الصلاحيات تُفحص في الخادم.
